# v0.8：一张本地窗口的权限边界

便捷模式不再要求先创建 manifest 或逐命令 permit。它不是取消授权，而是把授权粒度
改成“当前解锁期 + 确切项目 + 列出的凭证名称”，在一个本地窗口里与解锁一起完成。

## 允许与禁止

- `start` 只创建非秘密请求并启动 ATM 自己的有限期本机进程，不解密、不自动批准。
- 人在本地窗口查看完整路径、Key 名称、30 分钟固定期限和项目代码信任提示。
- 只接收已列出且确实缺少的 Key，不允许此流程覆盖已有凭证。新库明确设置并确认密码。
- 口令和 Key 不出现在父 CLI 的参数、环境、stdout、任务数据库或 README 中。
- 浏览器只保存本窗口的随机 bearer 于 sessionStorage；不保存密码或供应商 Key。
  fragment 用后移除，响应 no-store，严格 CSP、Host、Origin，敏感路由都需要 bearer。
- 这张窗口不暴露通用管理、Shell、原始 Key 读取、授权给另一系统用户等接口。
- 项目 grant 绑定实际当前解锁 ID，期限不超过会话；旧 grant 不能在下一次解锁复活。
- Key 范围是快照：后来新建的 Key 不自动加入；增加项目/Key 需再次确认，但仍有效的
  解锁会话不重新询问密码、不延长期限。拒绝保持拒绝，不自动重开窗口。
- 执行仍做确切项目与 Key 子集、同 UID、到期/撤销、冲突/上游过期检查。
  现有受限环境、输出/时限、请求幂等和启动前复查复用；无 Shell 字符串拼接。
- 老严格模式继续固定程序摘要和参数，未被改为便捷权限。

## 必须诚实说明的代价

便捷模式允许被信任项目中的代码发生改变，不再要求每次改脚本都手动批准。
程序、导入库和同 UID 恶意代码可以使用/外发已注入的 Key。因此这不是恶意 Agent 沙箱，
也不能保证“获得 Key 的程序绝不泄漏”。窗口的 bearer 不建立独立的硬件人类身份边界。
UI 引导人操作，Skill 禁止 Agent 读取 token 或代按授权，但同 UID 控制者并不受强隔离。
不支持远程浏览器公开管理。纯服务器/SSH继续采用显式受监督终端服务；原生 Passkey未实现。

默认窗口请求等待最多10分钟；批准后服务在固定会话结束时停止。关闭浏览器不立即锁定；
按钮或 `atm lock` 可提前锁定。锁定只阻止新接纳，不能收回已释放的秘密或取消上游交易。

## 名称清理与兼容

只安装 `atm` 入口，不再读取旧环境变量别名。新库使用当前格式标记。
已有密码库的加密校验标记和原生 keyring service只保留必要内部读取兼容，
不为了视觉改名而丢失主密钥映射、重建库或让旧 Key 无法解密。
Git历史、最初调研原始记录与历史测试回执未重写；它们不是当前使用入口。

## 验收

`tests/test_quickstart_v08.py` 验证实际 HTTP、真实新 CLI 进程、缺少 Key/新库、
一次密码后修改脚本继续、重复请求、取消、越权、撤销和下一会话不能复活旧授权。
`acceptance/test_quickstart_native_v08.py` 在允许的环境独立验证真实浏览器导航、CSP、
表单操作、刷新与锁定。禁止把内存页面或 Python HTTP 测试说成原生浏览器验收。
这是作者自审与自动测试，不是独立密码学安全认证。

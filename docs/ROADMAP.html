Agent Tool Maker

Agent 不只使用工具，也能制作工具。0.2 版把具体动作、通用协议桥接、外部交接和下一阶段验收分开记录。

157可发现动作入口
66原调研项逐项映射
120原生执行动作
14 + 23MCP 入口 + 外部交接
状态不是效果保证。原生执行、模拟协议测试和真实供应商验收不是同一回事。没有用私人账号发布、消费或部署；桌面/浏览器/人工交接不会因写出任务单就标记完成。

从当前版本走向完整工作流

0.3 · 实际账号验收

OAuth 登录和刷新

不复制明文令牌到 Agent 对话；撤销、失效和刷新失败均可复现。

0.3 · 实际账号验收

跨平台 CLI / SaaS 实测矩阵

先 Cloudflare、OpenCLI、Buffer、Figma；记录 OS、版本、权限和消费，不以模拟代替生产。

0.3 · 事件与长任务

Webhook 收件、签名校验、幂等与重放

Tally/Stripe/Resend 的重复或伪造事件不能引发重复发布/交付。

0.3 · 事件与长任务

长驻进程与挂起工作流管理

Tunnel/MCP 进程启动、停止、恢复和崩溃回收可观测。

0.4 · 垂直工具包

Marvelous Designer / CLO / FreeCAD

许可软件 + 版本匹配脚本 + 可编辑工程和导出文件真实验收；实物另外确认。

0.4 · 垂直工具包

社交发布与外包采购

账号/素材/时间或合同/金额有独立批准；超时先对账，不盲目重发/付款。

后续 · 强权限边界

受限执行侧车与可信批准界面

不能由同一不可信 Agent 自己给自己升权；明确操作系统威胁模型。

后续 · 可选托管平台

统一余额、Crypto、报价和预算预留

合法供给、并发预留、最大成本、退款和对账先于商业开放；BYOK 永久可用。

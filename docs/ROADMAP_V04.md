# v0.4 管理层状态与下一阶段

| 模块 | v0.4 状态 | 后续验收/实现 |
|---|---|---|
| Claude Code + Codex | 默认本地 Skill 注册、CLI/网页可管理 | 用户实际客户端加载、受管策略与新会话验收 |
| 工具开关 | 全局持久开关，执行器与路由均检查 | 每 Agent 的能力范围需另设可信执行身份 |
| Web console | loopback、鉴权、注册/工具/连接/任务摘要 | 独立安全审计；不支持对外暴露 |
| 凭证库 | 共用已有加密库，只写输入，按请求解锁 | 原生 keyring 锁屏与重启验收；通用 OAuth 刷新 |
| CLI 绑定 | 可在 UI 预览首次绑定；改变后拒绝静默重绑 | 带二进制差异的高级审阅页面 |
| origin/MCP/Maker | CLI 已有；本版 UI 不编辑 | schema 驱动表单、逐项批准与回读 |
| 业务执行 | 保留原有 CLI 和宿主批准要求 | Web 执行入口需独立审批/预算设计，不加任意 shell |
| 云端/跨设备 | 未实现，不自动共享本机凭证 | 明确身份、加密同步、授权与网络隔离 |

工具供给的 66 项路线图及 157 动作保持不变；管理层改动不等于各家上游生产兼容性验收。

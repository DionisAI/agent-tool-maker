# v0.6 扩展计划与边界

| 能力 | 本版状态 | 下一道验收 |
|---|---|---|
| 任意单行API Key命名槽 | 已实现，独立于工具目录 | 用户本机真实provider权限检查 |
| JSON API声明 | 已实现 | 真实供应商请求/响应独立验收 |
| OpenAPI3 JSON→单动作 | 子集已实现 | multipart、非JSON/流式、分页、更多鉴权逐项实现 |
| 自定义 CLI | 已实现，固定已绑定程序和argv | 每个CLI真实版本与官方登录验收 |
| 配方→Python CLI | 已实现，依赖ATM、定义摘要固定 | 可选发布包签名/注册中心，不把hash当信任 |
| Claude/Codex自动起草 | 接口已实现，真实子进程协议替身通过 | 用户已登录CLI小额实调；旧版本旗标不兼容时不降权 |
| 网页DOM配方执行 | 已实现，真实DOM/下载测试 | 原生导航、真实登录、每网站业务验收 |
| 自动探索任意URL和生成可靠选择器 | 未实现 | 观察/录制→生成→测试的有界Agent循环 |
| 视觉Canvas/iframe/复杂SPA和WebSocket | 未实现/有限 | 独立受控浏览器桥，不静默扩大白名单 |
| 设备本地加密网页登录态 | 已实现 | 原生keyring及多次任务登录生命周期实测 |
| 浏览器Cookie跨设备同步 | 明确不启用 | 单独设计按站点、设备和撤销风险审阅的机制 |
| 自动OAuth刷新、硬件passkey/MFA | 未实现 | 使用官方流程，必要时人交互，不绕过验证 |
| 自动重写并运行失败工具 | 明确不做 | 提交新草稿、独立验收、摘要更新及重新授权 |
| GitHub CI v0.6 | 本轮未执行 | 在可写连接/用户本机提交后检查该提交 |

所有v0.5同步/冲突/Broker期限规则继续成立。CLI凭证加密和网页登录态不是同一种资源。
权限变更仍由Owner批准；同UID不是恶意进程隔离，第三方程序与浏览器仍须信任。

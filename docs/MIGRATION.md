# 升级 ATM

从已审阅源码更新用户安装，不重建 vault、不复制另一份 Key。
让 Agent 读取根目录 SKILL.md，注册新版用户级 Skill；已有内容不同时先审阅，
再用 `atm setup --replace-skills --apply` 备份替换。

## v0.7 → v0.8

默认新增 `atm start` / `atm use`：一张本地窗口完成解锁和项目授权。
旧的 `access permit-exec` / `exec` 仍是严格模式，不被自动扩大权限。
旧客户端 profile 保留；便捷模式的临时 project profile 独立存储并绑定当前解锁期。

命令统一为 `atm`；旧命令别名和旧环境变量回退已删除。
显式路径顺序：`--home` → `ATM_HOME` → `~/.local/share/agent-tool-maker`。
如果过去自定义过状态目录，把同一个路径传给 ATM 或设置 ATM_HOME，**不要移动库来改名称**。
已注册的 Skill 应当固定正确的绝对程序路径和状态目录。

已有加密内容原样保留。新库使用当前格式标记；旧格式只保留内部只读兼容。
系统凭证库关联依赖状态目录路径，解锁失败时不得初始化覆盖。
同机已安装旧版命令时，升级同一个 pipx 安装会移除旧入口；不要删除未知来源的可执行文件。
Git 历史和历史测试回执不重写。

## 平台与授权

本地弹窗适用于有桌面浏览器的 macOS/Linux。没有浏览器的 SSH/服务器继续使用
高级指南的前台解锁方式；不得把本地管理台公开到网络来绕过限制。
不支持把同 UID 便捷授权变成跨 UID 任意代码提权。
多设备只同步获准 Key，不同步密码、解锁态、客户端 token 或浏览器 Cookie。

# v0.5 能力与验收地图

| 模块 | 本版 | 还没有完成 |
|---|---|---|
| 凭证多端 | 独立身份、指纹配对、收发白名单、加密文件收发、本地重加密 | 原生 R2/S3/WebDAV 同步服务、移动端 |
| 自动同步 | 显式启动的有限期前台 watch；已有共享/同步文件夹 | 安装系统服务、后台常驻、反熵确认/历史自动回收 |
| 冲突 | MV register、因果覆盖、tombstone、同值收敛、CAS选择完整版本、冲突阻断调用 | 多账号别名、冲突双存为两个账户、恶意写入节点共识 |
| Agent 权限 | 确切动作、定义和配置 pin、工作目录、权限类别、有效期、撤销 | 美元硬预算、跨 MCP/workflow 递归授权、动作级云端身份 |
| 免重复认证 | Owner 开启一次 Broker，多个新CLI进程复用；不自动退回直接 vault | 重启后无凭据解锁、通用 OAuth refresh、短期机器身份自动续约 |
| 系统隔离 | 同用户0600 socket；Linux可选group socket+peer UID | Windows、macOS跨用户认证、工具进程沙箱/网络egress |
| 网页 | 配对/范围预览、密文导入导出、冲突选择、本地撤销、grant预览应用 | 网页远程管理、后台启动进程、公开托管 |
| 恢复 | 旧格式库兼容；新机器新identity可从可信节点获得Key | 唯一主密钥遗失恢复、硬件绑定、全库旧备份回滚识别 |
| 安全保证 | 测试与明确威胁模型 | 第三方安全审计；不能宣称绝不泄露 |

本版保持157个供应商动作，不扩大虚构的生产兼容性。配置、同步协议与授权测试不等于供应商账户验收。
